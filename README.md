# MyMediaHub

## Your Media. Your Content. Your Hub.

MyMediaHub is a futuristic media tools website built using:

- HTML
- CSS
- Vanilla JavaScript

## Features

- Neon glowing design
- 3D floating effects
- Animated particles
- Glassmorphism cards
- Mobile responsive design
- Media URL validation
- Platform detection demo
- Animated FAQ
- Contact form demo
- Smooth animations

## Files

The project contains:

- index.html
- style.css
- script.js
- README.md

## How to Run

This website works directly as a static website.

Upload all files to the same GitHub repository.

Then enable GitHub Pages:

1. Open the repository.
2. Go to Settings.
3. Open Pages.
4. Select Deploy from a branch.
5. Select the main branch.
6. Select /(root).
7. Save.
